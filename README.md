# CheckoutParity waitlist

Demand-test interest page.
Outside SOLVD. Capture: thespencerlowe@gmail.com

## Quick start

Install deps, then start the Vite dev server (see package.json scripts: dev / build / preview).

## Form delivery

Default form action posts to formsubmit.co at the capture Gmail (see index.html).
First submit may need FormSubmit activation email confirmation.

Optional: copy .env.example to .env and set VITE_FORM_ENDPOINT to a Formspree URL.
When set, main.js overrides form action (FORM_ENDPOINT placeholder in docs).

## Deploy

Static Vite site. Import to Vercel (preset Vite, output dist) or Netlify/Pages.
Vercel may be unconnected; local preview is enough to review.
